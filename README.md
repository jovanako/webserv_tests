# Running tests

`make run_client`    - Runs Client tests  
`make run_request`   - Runs HttpRequest tests  
`make run_response`  - Runs HttpResponse tests  
`make run_config`    - Runs ConfigParser tests  
`make run_server_config` - Runs ServerConfig tests
`make run_location_config` - Runs LocationConfig tests
`make run`           - Runs all tests across all suites  
`make coverage`      - Runs all tests and prints code coverage for `../webserv`  
`make coverage_html` - Generates detailed HTML coverage report in `coverage_report/index.html` (requires `gcovr`)
